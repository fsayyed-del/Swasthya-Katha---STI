# Swasthya Katha (स्वास्थ्य कथा)
## Visual Multilingual Health Magazine & NACO Syndromic Case Management Platform

**Swasthya Katha** is a multilingual, visual digital health magazine designed to make sexual health and STI/RTI education understandable, destigmatizing, and actionable for all readers, including those with limited health literacy and on low-cost devices.

### Features
- **Magazine Mode:** Interactive 3D page flip experience with dual-page spreads on desktop and responsive swipe gestures on mobile.
- **Linear Mode:** 100% accessible, screen-reader friendly vertical flow adhering to WCAG 2.2 AA.
- **Facilitator Mode:** High-contrast projection and discussion prompts for Community Health Workers (CHWs).
- **Interactive NACO Color-Coded Kit Explorer:** Full coverage of the 7 NACO Syndromic Case Management Kits (Grey, Green, White, Blue, Red, Yellow, Black) with dual Learner and Clinical Facilitator views.
- **Synchronized Multilingual Audio:** Built-in speech synthesis with word and visual target highlighting.
- **Suraksha Referral & Helpline:** Direct access to National AIDS Helpline 1097 and Suraksha Clinic / ICTC referral support.

### Tech Stack
- **Framework:** Next.js 14 (App Router) & React
- **Language:** TypeScript (Strict Mode)
- **Styling:** TailwindCSS & Custom Design System Tokens
- **Icons:** Lucide React
- **Validation:** Zod
- **Testing:** Vitest

### Getting Started

```bash
# Install dependencies
npm install

# Run development server
npm run dev

# Run unit tests
npm test

# Build for production
npm run build
```
